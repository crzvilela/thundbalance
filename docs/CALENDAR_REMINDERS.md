# Calendar reminders

The events the app creates in Google Calendar (pack sessions and trial sessions) carry no reminders: every create and every update or patch sends `reminders = {"useDefault": false, "overrides": []}` (`event_format.NO_REMINDERS`), so the studio calendar shows none and an event that had the calendar's default reminders (10 minutes by email, 30 minutes popup) loses them the next time it is written (moving a session, editing the client, a trial confirmation or "Sincronizar con Google"). Reminders belong to the calendar of whoever sees the event, so this only decides what the studio calendar shows: guests use the notification defaults of their own calendar, which the app does not control. Events that already exist are not rewritten in bulk: "Sincronizar con Google" (per client, or per session) now also updates an event that still has reminders, so pressing it clears them.
